La Simona · web installer

Install La Simona from your browser

Plug your GaggiMate display into a computer, press a button, done. No tools to install. After this first time, updates arrive over Wi-Fi like normal.

Installs FIRMWARE_VERSION, the latest release

Flash at your own risk. La Simona is unofficial, experimental firmware, provided as is with no warranty of any kind. Installing it and running it on your machine is entirely at your own risk: I take no responsibility for any damage to your espresso machine, your GaggiMate boards or anything else, for injury, or for any other loss that comes from installing or using it. Espresso machines run on mains electricity and get very hot, so always unplug the machine from the wall before opening it or connecting anything inside it. Modifying your machine may also void its warranty. If you're not comfortable with that, don't flash it.

Before you start

  1. Use Chrome or Edge on a computer

    Flashing uses your browser's USB support (Web Serial), which only Chrome, Edge and Opera have, and not on phones.

  2. Export your profiles

    In the GaggiMate web app, Profiles → Export. The "keep everything" option below shouldn't touch them, but it's a cheap insurance policy.

  3. Connect the display with a USB-C data cable

    Some cables only charge. If nothing shows up when you press a button, try another one. You only need the display: the controller can update itself afterwards over Wi-Fi.

1. The display

For the LilyGo T-RGB 2.1" display from the GaggiMate kit. Pick one, press it, choose the display's port in the pop-up, and leave it plugged in until it says it's done (about a minute).

Recommended

Switch to La Simona, keep everything

For a display already running GaggiMate. Writes only the firmware, so your Wi-Fi, settings, profiles and shot history stay put. When it asks "Erase device?", leave the box unticked and press Next: ticking it wipes everything.

Your browser can't flash over USB. Open this page in Chrome or Edge on a computer. Flashing needs this page over https.
New or broken display

Clean install

Writes everything fresh, including a new set of default profiles, so your own profiles and shot history are replaced. It asks whether to erase the device too: say yes to also wipe settings and Wi-Fi, and the setup wizard runs on first start.

2. The controller

The controller board sits inside the machine, so let the display update it over Wi-Fi instead of opening anything up.

  1. Over Wi-Fi (no cables)

    Once the display is running La Simona, open the web app and go to Settings → System & Updates. Choose the Stable channel, press Save Channel & Refresh, then Update next to the controller. It takes about two minutes and goes over Bluetooth from the display.

  2. Over USB, if the controller won't update

    Unplug the machine from the wall first, then connect the controller's USB-C port to your computer. When it asks "Erase device?", either answer is fine: your settings live on the display.

    Your browser can't flash over USB. Open this page in Chrome or Edge on a computer. Flashing needs this page over https.

If it won't connect

  1. Put the board into download mode

    Unplug it, hold its BOOT button (marked SW1 on the display), plug it back in, then let go. Press the install button again.

  2. Close anything else using the port

    Only one program can talk to the board at a time: close the Arduino IDE, PlatformIO's monitor or other flashing tabs.

  3. Rather use the command line?

    Save flash.py, run pip install esptool, then python3 flash.py. It fetches the latest release and flashes the display, then the controller. Unlike the first option above, it replaces the display's profiles, so export them first.

Going back to official GaggiMate is just as easy: use the official web flasher, or choose the Upstream update channel and update both boards over Wi-Fi. This isn't official GaggiMate firmware, so please don't ask the GaggiMate team for help with it.
